# Projeto Alura: Jogo de Cartas

* Breve Resumo:

Projeto voltado ao desenvolvimento baseado em orientação a objetos, utilizando conceitos de herança, polimorfismo, composição e encapsulamento. Todos os conceitos foram aplicados em um projeto que envolve classes, métodos e funções:

* Herança
* Composição
* Encapsulamento
* Polimorfismo
